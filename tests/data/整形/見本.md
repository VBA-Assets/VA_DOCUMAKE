# 主張
## 弁済の事実
被告は、令和７年５月１日、*原告*に対し、__借入金の全額__を弁済した（[[乙1|乙第１号証]]）。弁済の方法は、原告の指定する銀行口座への振込みである。
## 証拠
弁済の事実は、振込みの控え（乙第１号証）と、原告の受領を示す電子メール（乙第２号証）から明らかである。
--: 以上
# 別紙　弁済の経緯
- 被告は、令和７年４月２０日、原告から返済の催告を受けた。
- 被告は、同年５月１日、全額を振り込んだ。
