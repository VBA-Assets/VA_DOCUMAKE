VA公用文AI 試作の手順書
# 概要
この文書は、VA公用文AIの試作で、VA公用文の出力と Python の出力を比べる手順を示す。比べる値は、字のページ・行・左端からの位置である。
# 準備
## 必要なもの
- Windows 版の Word と VA公用文 Ver8D3
- Python 3.14 と、reportlab、PyMuPDF
## 見本の作成
見本は、VA公用文の ai-prompt.md の形式で、マークダウンで書く。見出しは # の数で階層を表す。
# 手順
## VA公用文で整える
別に起動した Word で、見本を整え、字の位置を読み取る。読み取った値は JSON で保存する。
## Python で組む
typeset.py で見本を組み、PDF を書き出す。
## 比べる
compare_word.py で、次の値を数える。
1. 同じページの同じ行に入った字の数
2. 左端からの位置の差が 1pt 以内の字の数
3. 行の切れ目が一致した行の数
