# 第1章 ツールの概要

## 1.1 これは何をするツールか

VA DocuMakeは、弁護士が AI を使って書面を起案・推敲するときに、AI の利用について求められていることを守りやすくするためのツールです。依頼者などの実名を AI に渡さずに済ませ、裁判所提出書類・公用文・契約書などを VA公用文（Word のアドイン）で整えたものと同じ書式の PDF にします。

弁護士が AI を使うときには、次のことが求められています。

- 秘密を守ること（弁護士法23条、弁護士職務基本規程23条。事務職員などにも守らせること：同規程19条）
- 事務所として、情報の取扱方法を定めること（日弁連の弁護士情報セキュリティ規程3条2項。2024年6月1日施行）
- AI に入力する情報を管理すること（利用規約の確認、学習に使わせない設定、匿名化・抽象化など。東京弁護士会「弁護士業務における生成AIサービスの適正利用ガイドライン」など）
- AI の出力を確かめ、最終的な責任を負うこと

VA DocuMakeは、このうち、実名を AI に渡さないこと（仮名化と、実名への戻し）と、情報の取扱方法を定めるための材料（1.4 の表）を受け持ちます。AI の設定（第4章）、出力の確認、依頼者への説明は、利用者が行ってください。

VA公用文と VA仮名化は Word のマクロなので、マクロの使用を禁止されているパソコンでは使えません。VA DocuMakeは Word のマクロを使わない、独立したプログラムです（実行ファイル〔.exe〕の起動が制限されている場合は、事務所の管理者に確かめてください）。

- 見出しの番号・インデント・1行の字数・1ページの行数・余白は、VA公用文と同じ規則で付けます。文書の種類は、VA公用文と同じ7種類（裁判所提出書類・内容証明・公用文・契約書1・契約書2・ビジネス文書・技術文書）です。
- 文章は、マークダウン（`#` で見出しを表すなどの、簡単な書き方）で書きます。AI（Claude など）に頼めば、この書き方で書いてくれます。
- 文章の起案や推敲に AI を使うときは、依頼者などの名前を記号（〔人名Ａ〕など）に置き換えてから渡します。AI の回答を取り込むと、記号は元の名前に戻ります。
- 書式を付けるのに、AI は使いません。決まった規則で動くプログラムが付けるので、書式を整えるときに文章が書き換えられたり、省かれたりすることはありません。

## 1.2 できること・できないこと

**できること**

- 書いた文章・貼り付けた文章を、VA公用文と同じ書式の PDF にする（確認表示で、仕上がりを見ながら直せます）
- 見出しの番号、表（罫線）、目次、ページ番号、行番号
- 表題・中央揃え・右揃え・1行目の字下げ・インデント・太字・傍点・均等割付・改ページ・セクション区切り
- 名前などを記号に置き換えて AI に渡し、AI の回答を取り込んで実名に戻す
- 印刷
- 内容証明の字数・行数の確かめ（VA内容証明郵便と同じ）

**できないこと**

- 図・画像・脚注（ヘッダー・フッターの文字は書けます。3.6）
- 変更履歴・コメント（事務所の中で回覧して直す使い方には向きません）
- 表のセルの結合、列の幅を手で決めること
- Word の形式（.docx）での保存（出力は PDF だけです）
- AI のチャット画面に直接書いた実名を防ぐこと
- 文章の中身（日付・金額・地域の組み合わせなど）から、人や会社が推測されるのを防ぐこと

## 1.3 安全のための作り

- **外部と通信しません。** 更新の確認、利用状況やエラーの送信もしません。
- **実名と記号の対応表は、VA DocuMakeの中（メモリ）にだけ持ちます。** どのファイルにも書かず、VA DocuMakeを閉じると消えます。開き直したときは、構文ファイルと書式付きファイル（PDF）を突き合わせて、対応表を作り直します。
- **AI に渡す構文ファイルには、実名・文書の名前・フォルダの場所を書きません。** ファイルの名前も、意味のない文書ID（`K7Q29XMD.vadm` など）にしています。
- **書式付きファイル（PDF）には、元の文章・設定・作成者などの情報を埋め込みません。** 構文ファイルと結び付けるための文書ID と版だけを、PDF の識別子の欄に入れます。
- **クリップボードは、ボタンを押したときだけ使います。**

## 1.4 どの情報がどこへ行くか

事務所の情報の取扱方法（日弁連の弁護士情報セキュリティ規程に基づくもの）を定めるときに、そのまま引けるようにまとめました。

| 情報 | 置き場所 | AI に渡るか |
|---|---|---|
| 実名の文章（仕上がり） | 書式付きファイル（PDF）。利用者が選んだ場所 | 渡りません（AI に渡さないでください） |
| 仮名化した文章と、AI への指示 | 構文ファイル（.vadm）。構文ファイルのフォルダ | 利用者が渡したときに渡ります |
| 実名と記号の対応表 | VA DocuMakeのメモリの中だけ | 渡りません |
| 設定（文書の種類・ページ番号・行番号、保存したフォルダの一覧、ウィンドウの大きさ、エディターの見た目、AI への指示） | このパソコンの設定ファイル（%APPDATA%\VA DocuMake\settings.json） | 渡りません（AI に渡さないでください） |
| AI のチャット画面に書いた指示 | AI のサービス | 渡ります（実名を書かないでください） |

# 第2章 導入方法

## 2.1 配布物の構成

VA DocuMakeは、「VA DocuMakeシリーズ（統合版）」のインストーラーに入っています（VA mints・VA FAX も入っています）。インストールの途中で、入れるツールを選べます。インストールすると、次のものが入ります。

| ファイル | 内容 |
|---|---|
| `VA_DocuMake.exe` | VA DocuMake本体（Python などを別に入れる必要はありません） |
| マニュアル（フォルダ） | このマニュアル（PDF） |
| `LICENSE.txt` | ライセンス（GNU Affero General Public License 第3版） |
| `THIRD_PARTY_NOTICES.txt` | VA DocuMakeが使っている部品のライセンスの表示 |

ソースコードは、GitHub で公開しています（第5章）。

## 2.2 起動方法

1. スタートメニュー（またはデスクトップ）の「VA DocuMake」を押します。
2. 構文ファイル（.vadm）をダブルクリックしても、VA DocuMakeが起動して、その文書を開きます。

Windows の SmartScreen などが警告を出すことがあります。電子署名のない実行ファイルに出る、一般的な警告です。気になる場合は、公開しているソースコードを確かめるか、ご自身でビルドしてお使いください。

## 2.3 動作環境

- Windows 10・11
- ＭＳ 明朝・ＭＳ ゴシック（Windows に最初から入っています。PDF に埋め込みます）

配布している実行ファイル（exe）は、Windows 用です。Mac では、公開しているソースから動かせます（手順はソースの README。動作は保証しません）。Mac では、ＭＳ 明朝の代わりに、ソースに同梱した IPA明朝・IPAゴシックを PDF に埋め込みます。字の位置・行の切れ目・ページの切れ目は Windows と同じで、字の形だけが違います。［印刷］は使えないので、保存した PDF を開いて印刷してください。

## 2.4 設定ファイルと、アンインストール

- 設定は、このパソコンの `%APPDATA%\VA DocuMake\settings.json` に覚えます（文書の中身は書きません）。
- 構文ファイルは、決まったフォルダ（`ドキュメント\VA DocuMake\構文ファイル`）に保存します。オプションで変えられます（3.13）。
- アンインストールしても、作った書式付きファイル（PDF）と構文ファイルは消えません。

# 第3章 基本的な使い方

## 3.1 画面の見方

VA DocuMakeは、1つの文書を2つのファイルに保存します。呼び方は、Windows のメモ帳のマークダウンの表示（「書式付き」と「構文」）に合わせています。

| ファイル | 中身 | AI に |
|---|---|---|
| **書式付きファイル（PDF）** | 書式を整えた仕上がり。**実名**のまま | 渡さない |
| **構文ファイル（.vadm）** | マークダウンの記号が見える文章。仮名化した語は記号（〔人名Ａ〕など）に置き換え済み | 渡す |

画面は、左が確認表示、右がエディターです。

- **確認表示（左）**は、実名に戻した仕上がり（書式付きファイルと同じ書式）を表示します。仮名化した語は、字の地を薄い緑にして示します（PDF には色は付きません）。上に書式付きファイルの名前、ページ送り・表示の倍率・［印刷］のボタンがあります。確認表示の字を押すと、エディターのカーソルがその字に動きます。
- **エディター（右）**は、仮名化した語を記号（〔人名Ａ〕など）で表示します。エディターに見えているものが、そのまま構文ファイルの中身になります。上に構文ファイルの名前と［パスをコピー］があります。エディターでカーソルを動かすと、確認表示にその字のあるページが出ます。
- **リボン（右の上）**には、組ごとにボタンを並べています。

| 組 | ボタン |
|---|---|
| ファイル | ［開く］［保存］［閉じる］［オプション］ |
| AI 連携 | ［選択範囲を仮名化］［コピー］［貼り付け］ |
| スタイル | 文書の種類・ページ番号・［行番号］、［見出し］［箇条書き］［段落番号］ |
| 書式 | ［太字］［傍点］［均等割付］、［表題］［中央］［右］［字下げ］［インデント］［ヘッダー］ |
| 挿入 | ［改ページ］［セクション区切り］［目次］ |
| 編集 | ［検索］［置換］ |
| 表示 | ［蛍光ペン］ |

- **仮名化した語（右の下）**には、仮名化した語と記号の一覧を出します。［解除］で仮名化をやめ、［変更］で記号と元の語を変えられます。
- 保存していない変更があると、ウィンドウの題に「＊」が付き、［保存］のボタンが青い枠で囲まれます。
- ボタンにマウスを重ねると、説明が出ます。

## 3.2 文書を作る流れ

1. 「スタイル」で、文書の種類とページ番号を選びます（行番号が要るときは、［行番号］にチェックを付けます）。
2. エディターに文章を書くか、貼り付けます（3.3）。
3. 見出し・配置などの書式を付けます（3.3〜3.6）。確認表示で仕上がりを見ながら直します。
4. 依頼者などの名前を仮名化します（3.8）。
5. ［保存］を押します。初めて保存するときは、書式付きファイル（PDF）の名前と置き場所を決めます。構文ファイルは、構文ファイルのフォルダに自動で保存されます。
6. AI に起案や推敲を頼むときは、構文ファイルを AI に渡し、AI の回答を取り込みます（3.9）。
7. 仕上がったら、書式付きファイル（PDF）を提出に使います。

**保存について**

- 書式付きファイルと構文ファイルは、いつも同じ版で一緒に保存します。どちらか一方だけを保存することはありません。
- 自動では保存しません。こまめに［保存］（Ctrl+S）を押してください。
- 書式付きファイルを、ほかのソフト（Acrobat など）で開いたままでは保存できません。閉じてから保存してください。

## 3.3 文章の書き方（マークダウン）

文章は、VA公用文と同じマークダウンの形で書きます。AI に「マークダウンで書いて」と頼めば、この形で書いてくれます。

| 書き方 | 意味 |
|---|---|
| `# 見出し` | 見出し。`#` の数でレベルを表します（`#` が第１、`##` が１、`###` が(1)…。番号の形は文書の種類で変わります）。**見出しに番号は書きません**（自動で付きます） |
| `- 項目` | 箇条書き |
| `1. 項目` | 段落番号（自動で ① ② … になります） |
| 空の行 | 1行あけます |

- `#` `-` `1.` の後には、半角の空白を入れます。空白がないと、見出しなどになりません（「-1度」「2026.10.23」で始まる文の字が消えないようにするためです）。
- 「スタイル」の［見出し］［箇条書き］［段落番号］を押すと、選んだ行（選んでいなければカーソルの行）の先頭に `## ` `- ` `1. ` を付けます（ほかの2つの記号が付いていれば、付け替えます）。もう一度押すと、記号を外して本文に戻します。字を打っていない行で押すと、記号だけを付けるので、続けて字を打てます（字のある行と一緒に選んだ空の行には付けません）。［見出し］で付くのはレベル2（`##`）です。レベルを変えるときは、エディターで `#` の数を直すか、Alt+Shift+←／→（3.4）を使います。ボタンを押さずに、ショートカットキーだけでも見出しにできます（本文の行や字を打っていない行で Alt+Shift+← か Alt+Shift+→ を押すと、直前の見出しと同じレベルの見出しになります。前に見出しがなければ、［見出し］と同じ `##` になります）。
- 1つの段落は1行に書きます（段落の途中で改行しません）。
- 最初の見出しより前の行（事件番号・当事者・表題・日付・宛先など）には、見出しの番号やインデントは付きません。
- 見出しの後に右揃えの行（「以上」など）が来ると、そこから先（次のセクション区切りまで）は、見出し・箇条書き・段落番号に変えず、インデントも付け直しません（VA公用文と同じです）。
- `#` だけの行のすぐ後に見出しを書くと、2つの見出しを1行にまとめます（「第１　１　当事者」。複合見出し。契約書1・技術文書ではまとめません）。

**貼り付けた文章について**

- AI の画面や Obsidian などから貼り付けた文章の、マークダウンにない要素（コードブロックの記号 ```、先頭のフロントマター、水平線、`__x__` `_x_` の強調、WikiLink）は、組むときに取り除きます（VA公用文の一括整形と同じです）。
- Word の文書から写した、番号を手で書いた見出し（「第１　請求の趣旨」など）は、そのままでは本文になります。仮名化して保存した後、AI に「見出しの番号を外し、# の数でレベルを表す形に直して」と頼むと、マークダウンの形に直せます（3.9）。

## 3.4 書式の記号とボタン

配置などの書式は、行の先頭や字の前後に記号を書いて付けます。記号はボタンで付け外しできるので、手で書く必要はありません。同じボタンをもう一度押すと、記号を外します。

| 記号 | 意味 | ボタン |
|---|---|---|
| `:=: ` | 表題（文書の種類ごとの表題の配置） | ［表題］ |
| `:-: ` | 中央揃え（「記」など） | ［中央］（Ctrl+E） |
| `--: ` | 右揃え（日付・作成者・「以上」など） | ［右］（Ctrl+R） |
| `-> ` | 段落の1行目だけを1字下げる | ［字下げ］ |
| `+2 ` | 段落の左のインデントを全角2字にする（数字が字数。手で直します） | ［インデント］（Ctrl+I） |
| `**字**` | 太字（ＭＳ ゴシックで描きます。字の幅は変わりません） | ［太字］（Ctrl+B） |
| `*字*` | 傍点（字の上に黒丸） | ［傍点］ |
| `[原告]{5}` | 均等割付（角かっこの中の字〔例では「原告」〕を、波かっこの字数〔例では5字〕の幅に割り付けます。字数は手で直します） | ［均等割付］ |
| `==字==` | 蛍光ペン（確認表示だけで黄色に塗ります。PDF と印刷には出ません） | ［蛍光ペン］（Ctrl+Alt+H） |

- 配置の記号は、マークダウンの表の区切りの行（3.5）と同じく、コロンのある側に字を寄せます（`:=:` の `=` は表題）。行の先頭の記号（`:=:` `:-:` `--:` `->` `+2`）の後には、半角の空白を1つ置きます。空白がないと記号になりません（字のまま残ります）。
- 記号は、エディターで青い字で示します。太字の字は太く、傍点の字は下線、蛍光ペンの字は黄色の地で示します。
- ［太字］を見出しの行で押すと（字を選ばずに押すか、見出しの字をすべて選んで押すと）、同じレベルの見出しをすべて太字にします。もう一度押すと、同じレベルの見出しの太字をすべて外します。
- 太字と傍点を重ねると `***字***` になります。［太字］［傍点］は、それぞれ別に付けたり外したりできます。
- 傍点を付けても、行の折り返しやページの区切りは変わりません（表の中では、傍点のある行だけ、少し高くなります）。`2*3*4` のように、`*` の外側に英数字が続くものは、傍点になりません。
- `->` を見出しの後の段落に使うと、右揃えの行と同じく、そこから先は見出しなどに変えません。
- `+2` の段落は、見出し・箇条書き・段落番号に変えず、見出しのレベルに合わせたインデントも付けません。字下げと一緒に使うときは `+2 -> 本文` と書きます。

**見出しのレベルを変える・本文に戻す（Word と同じキー）**

- Alt+Shift+← で見出しのレベルを1つ上げ、Alt+Shift+→ で1つ下げます。本文の行で Alt+Shift+← か Alt+Shift+→ を押すと、直前の見出しと同じレベルの見出しになります（前に見出しがなければ `##`。公用文では、第1レベルは基本的に使わないためです。字を打っていない行では、見出しの記号だけを付けます）。
- `#` で Alt+Shift+← を押すと、見出しなし（本文）になります。`#########` で Alt+Shift+→ を押したときも、見出しなしになります。
- Ctrl+Shift+N で、見出し・箇条書き・段落番号・配置の記号を外して、ふつうの本文に戻します。
- どれも、選んだ行すべてに効き、Ctrl+Z 1回で元に戻せます。

**Ver.120 までに作った構文ファイル**

Ver.130 で、記号の形を改めました。Ver.120 までの記号（`{右}` など）は記号として読まないので、前の版で作った構文ファイルを開くと、配置などが外れ、記号が字のまま残ります。エディターで、次のとおり書き換えてください（［置換］〔Ctrl+H〕が便利です。行の先頭の記号の後には、半角の空白を1つ置きます）。

| Ver.120 まで | Ver.130 から |
|---|---|
| `{表題}` `{中央}` `{右}` `{左}` | `:=: ` `:-: ` `--: ` `:-- ` |
| `{字下}` | `-> ` |
| `{イン:2}` | `+2 ` |
| `{改ページ}` `{セクション区切り}` | `<<<` `<<<=` |
| `{目次}` `{目次:2}` | `[TOC]` `[TOC:2]` |
| `{均等:5}原告{均等}` | `[原告]{5}` |

## 3.5 表（罫線）の書き方

罫線のある表は、マークダウンの表の形で書きます。AI に「表にして」と頼めば、この形で書いてくれます。

```
| 項目 | 金額 |
|---|---:|
| 休業損害 | 1,080,000 |
| 通院交通費 | 25,000 |
```

- **1行目**は見出しの行、**2行目**は区切りの行（見出しの行の下の線）、**3行目から**が中身です。
- 列は `|` で区切ります。セルの字の中に `|` を書くときは、`\|` と書きます。
- 行の初めと終わりの `|` は、あってもなくてもかまいません。

**列の字の配置（区切りの行で決めます）**

| 区切りの行の書き方 | その列の字 |
|---|---|
| `---` または `:---` | 左にそろえる（長いときは両端をそろえて折り返す） |
| `:---:` | 中央にそろえる |
| `---:` | 右にそろえる（金額などに使います） |

区切りの行のセルにカーソルを置いて、「書式」の［中央］［右］を押しても変えられます。もう一度押すと、左に戻ります。

**見出しの行の下を2重線にする**

区切りの行の `-` を `=` にします（`|===|===:|`）。`:` の付け方は同じです。

**1つのセルだけ配置を変える**

セルの先頭に `:-- ` `:-: ` `--: ` を書きます（`| :-: 項目 | --: 金額 |`）。列の配置より優先します。セルにカーソルを置いて［中央］［右］を押しても、付けたり外したりできます。

**セルの中でも使える書式**

太字（`**字**`）・傍点（`*字*`）・蛍光ペン（`==字==`）・均等割付（`[原告]{5}`）は、セルの中でも使えます。

**表の組み方（自動で決まること）**

- 表の左端は、そのとき書いている見出しの本文の位置にそろい、右端は本文の右端まで広がります。
- 列の幅は、セルの字の長さから自動で決まります。短いセルは折り返さず、長い説明の列だけが折り返します。
- ページの下に入りきらない行は、次のページに送ります（1つの行を2ページに分けることはしません。見出しの行は、次のページで繰り返しません）。
- セルを結合すること（2つのセルを1つにまとめること）や、列の幅を手で決めることはできません。表の形を変えたいときは、AI に直させると早く済みます。

## 3.6 目次・改ページ・セクション区切り・ヘッダー

「挿入」のボタンで、カーソルの行の前に、その行だけの記号を入れます。

| 記号 | 意味 | ボタン |
|---|---|---|
| `<<<` | この位置でページを改めます（見出しの番号は続きます） | ［改ページ］（Ctrl+Enter） |
| `<<<=` | ページを改め、見出しの番号を第１から振り直します（別紙を独立した文書として組むときなど） | ［セクション区切り］ |
| `[TOC:3]` | この位置に、見出しのレベル3までの目次を組みます（数字は載せるレベル。手で直します） | ［目次］ |

- 目次は、VA公用文で整えた文書に Word の目次（自動作成の目次 1）を入れたものと同じ書式です。題（「目次」など）は付かず、改ページもしません。要るときは、`:-: 目次` の行や `<<<` を書き足してください。
- 改ページの位置を動かすときは、記号の行そのものを動かします。

**ヘッダー・フッター**

行の先頭に `[HEADER] ` を付けると、その行をヘッダー（最初のページと、セクション区切りの直後のページの上の余白）に、`[FOOTER] ` を付けると、フッター（各ページの下の余白）に出します。本文の行は使いません。

| 記号 | 意味 | ボタン |
|---|---|---|
| `[HEADER] ` | この行をヘッダーに出します（ページ番号が右上ならその下、そうでなければ上の余白の、ページ番号と同じ高さから） | ［ヘッダー］ |
| `[FOOTER] ` | この行をフッターに出します（ページ番号が下ならその上、そうでなければ下の余白の、ページ番号と同じ高さ） | なし（手で書きます） |

- 例：`[HEADER] --: 令和７年（ワ）第１２３号` と書くと、事件番号を最初のページの右上に出します。
- 配置の記号（`:-: ` `--: ` など）、`+2 `、太字・傍点・均等割付と一緒に使えます。［ヘッダー］（「書式」の組の［インデント］の下）は、選んだ行（なければカーソルの行）の先頭に記号を付け、もう一度押すと外します。見出しの行には付けません。
- ヘッダーは、文書の最初のページと、セクション区切り（`<<<=`）の直後のページだけに出ます。「別紙」「付紙」などを書くときに使います（例：`<<<=` の次の行に `[HEADER] --: 別紙１`）。フッターは、書いたセクションのすべてのページに出ます。どちらも何行でも書け、書いた順に並びます。
- ヘッダー・フッターの行を書いても、本文の折り返しやページの区切りは変わりません。余白に入りきらないときは、ページ番号ごと用紙の端の側へずらします。それでも入らないときは、エディターの下の欄に「ヘッダーが上の余白に入りきらず、本文に重なっています」と出るので、行を減らしてください（上下の余白の狭い公用文・契約書1で、ページ番号が下のときは、ヘッダーは3行、フッターは1行までです）。
- 内容証明では、ヘッダー・フッターを付けません。

## 3.7 文書の種類・ページ番号・行番号

「スタイル」の選択欄で、文書の種類とページ番号を選びます。文書ごとの設定で、構文ファイルにも書いておくので、開き直しても残ります。新しい文書は、前に使った設定で始まります。

- **文書の種類：** 裁判所提出書類・内容証明・公用文・契約書1・契約書2・ビジネス文書・技術文書（VA公用文と同じ）
- **ページ番号：** なし・右上・中下・中下（飾り）・右下（VA公用文と同じ）

**行番号**

ページ番号の下の［行番号］にチェックを付けると、左の余白に行番号が付きます（VA公用文の行番号と同じです）。

- 5行ごとに番号を出し、ページごとに 1 から数えます。空の行も1行と数え、表の中の行は数えません。
- 文書の種類が内容証明のときは、付けられません。

**内容証明の字数・行数の確かめ**

文書の種類が「内容証明」のときは、［保存］で書式付きファイルを作る前に、VA内容証明郵便と同じく、1行20字以内・1枚26行以内かを確かめます。

- ページ番号が「なし」でなければ、「なし」にして知らせます。
- 超えた所があれば、エディターのカーソルをその行に動かし、保存をやめて直すか、このまま保存するかを尋ねます。
- VA DocuMakeの内容証明は1行19字・26行で組むので、ふつうは超えません。超えるのは、半角の英数字の多い行（半角も1字と数えます）や、表の中の行などです。

## 3.8 仮名化

AI に渡す前に、依頼者などの名前を記号に置き換えます。

1. エディターで、名前などの語を選びます。
2. 「AI 連携」の［選択範囲を仮名化］を押し、種別（人名・法人・地名・番号・その他）を選び、記号の字を入れます。記号の字は、自動では入りません。画面には、この文書でその種別に使っている記号と、解除した記号を示します。
3. エディターの同じ語が、すべて記号（〔人名Ａ〕など）に置き換わります。

**記号の字の決め方**

- 記号の字には、英字・数字・漢字・かなを使えます。字数の制限はありません（例：〔人名Ａ〕、氏名のイニシャルの〔人名ＹＴ〕、〔人名１〕、〔人名甲〕、〔法人相手方〕）。半角の英字・数字や小文字で入れても、全角の大文字になります。空白・括弧・「*」「|」などの記号は使えません（マークダウンの記号と紛れるためです）。
- 1つの文書の中では、同じ記号を2つの語に使えません。
- 解除した記号は、また選べます。前と同じ語に付けるときは、そのまま付けます。**別の語に付けるときは、付けるかを尋ねます。** 同じ AI の会話の前の回答にその記号が残っていると、取り込むときに新しい語に戻ってしまうためです。会話を続けているときは、別の記号を選んでください。
- 同じ事件の書面では、同じ人に同じ記号を付けると、AI が人を取り違えにくくなります（3.15）。たとえば「依頼者はＡから、相手方はＸから」「当事者は登場する順にＡ・Ｂ・Ｃ」のように、自分の決まりを作って、書面をまたいでそろえてください。

- 仮名化した語をエディターで打ったり、貼り付けたりすると、自動で記号に置き換わります。**エディターに実名の字が見えていれば、それは仮名化していない語です。** AI に渡す前に、エディターを見て確かめてください。
- 確認表示（左）では、仮名化した語の字の地を薄い緑で示します。
- 仮名化をやめるときは、右の下の一覧で語を選んで［解除］を押します（エディターの記号は元の語に戻ります）。
- 検索・置換では、仮名化した語（実名）を入れても、エディターの記号を探します。
- 一覧で語を選んで［変更］を押すと（行をダブルクリックしても同じです）、元の語と記号を変えられます。
  - **元の語：** 登録した語に誤り（誤字、選んだ範囲の過不足など）があったときに直します。記号はそのままで、文章の中のその記号が、すべて新しい語になります。［解除］して仮名化し直すより手早く、記号も変わりません。
  - **記号：** 前の書面と記号をそろえるときなどに変えます。エディターの記号も変わります。AI とのやり取りの途中で変えると、前の回答にある前の記号は、取り込むときに「仮名化した語にない記号」として知らせます。
- 解除した語（または、変える前の元の語）が文章に残っていると、保存するときに知らせます。そのまま保存すると、構文ファイル（AI に渡すもの）に実名のまま書かれるためです。［いいえ］を押すと、残っている所を選んで見せます。

## 3.9 AI とのやり取り

**Claude（デスクトップ・Web）に頼む**

1. ［保存］を押してから、構文ファイルを AI に渡します。次のどちらかの方法があります。
   - エディターの上の［パスをコピー］を押し、Claude の添付の画面の「ファイル名」の欄に貼り付けて、構文ファイルを添付します。
   - 「AI 連携」の［コピー］を押し、構文ファイルの中身を Claude のチャット画面に貼り付けます（保存していない変更があれば、先に保存します）。
2. 頼みたいことを書いて送ります（実名は書かないでください。第4章）。
3. AI は、回答をコードブロック（枠で囲まれた部分）で返します。コードブロックのコピーのボタンを押して写します。
4. VA DocuMakeの「AI 連携」の［貼り付け］を押します。記号を実名に戻してエディターに取り込み、新しい版で保存します。

**取り込んだ後**

- AI の回答で変わった段落・増えた段落には、エディターの右端に青い線を付けます（次に取り込むまで残ります）。
- 次のことがあれば、知らせます：仮名化した語にない記号（AI が作った記号など。記号のまま入ります）、なくなった記号、なくなった配置などの記号、消えた段落（AI が要約・省略していないかを確かめてください）。
- 取り込む前に戻すときは、エディターで Ctrl+Z を押します（1回で戻ります）。
- 前の版をもとにした回答なら、画面の下に示します。AI は、会話の途中では最初に渡された版の番号を書き続けることがあるので、取り込みは止めません。
- 区切りの行（`==== VA DocuMake 文書ID …`）のない回答や、別の文書の回答は、取り込みません。

**Claude Code に頼む**

1. Claude Code の作業フォルダを、「構文ファイル」フォルダにします（第4章の注意を守ってください）。
2. VA DocuMakeで［保存］を押してから、［パスをコピー］を押し、Claude Code に「このファイルを直して：」と書いて、パスを貼り付けます。
3. Claude Code が構文ファイルを書き換えたら、VA DocuMakeの画面に戻ります。外で書き換えられたことを知らせるので、取り込みます（［貼り付け］と同じく取り込みます）。

**頼み方の例**

- 「第３の段落を、もう少し短く書き直して」
- 「被告の主張に対する反論を、見出しを立てて書き足して」
- 「表にして」（マークダウンの表で書いてくれます）
- 「見出しの番号を外し、# の数でレベルを表す形に直して」（Word から写した、番号を手で書いた文書を、マークダウンの形にするとき）
- 「蛍光ペンの部分を直して」（蛍光ペンで目印を付けた所だけを直させるとき）

構文ファイルの先頭には、記号や配置の記号を変えないことなどを求める AI への指示が付いています（3.13 で確かめ・直せます）。

**同じ会話で別の書面も頼むときは、記号をそろえてください。** 記号は、文書ごとに利用者が選ぶので、そろえていないと、同じ人が文書によって別の記号になります（3.8・3.15）。

## 3.10 開く・閉じる

［開く］（Ctrl+O）で、次のファイルを開けます。

- **構文ファイル（.vadm）：** 同じ文書の書式付きファイル（PDF）を、これまでに保存したフォルダから探し、2つを突き合わせて、記号を元の語に戻します。見つからないときは、PDF を選ぶか、PDF なしで開くかを尋ねます。PDF なしで開いたときや、元の語が分からない記号があるときは、記号ごとに元の語を入力します。
- **書式付きファイル（PDF）：** VA DocuMakeで作った PDF なら、同じ文書の構文ファイルを探して開きます。構文ファイルが見つからない PDF や、ほかのソフトで作った PDF は、字を取り出して、素の文章として開きます（見出し・配置は戻りません）。
- **テキスト・マークダウン（.txt・.md）：** そのまま開きます。

［閉じる］は、今の文書を閉じて、新しい文書にします（VA DocuMakeは終わりません）。

- 保存していない変更があれば、保存するかを尋ねます。
- 閉じると（VA DocuMakeを終えたときも）、仮名化した語の一覧（実名と記号の対応）は消えます。AI とのやり取りが終わっていなくても、開き直せば、構文ファイルと書式付きファイルを突き合わせて、仮名化した語の一覧を作り直します。

**新しい文書を作るとき**

［閉じる］で新しい文書にしてから書き始めます。決まった文言（テンプレート）を使うときは、テキストやマークダウンのファイルを［開く］で開きます（3.15）。

- 過去の文書（構文ファイル・書式付きファイル）を［開く］で開いて書き換え、［保存］すると、その文書が上書きされます。過去の文書をもとに、別の文書を作らないでください（3.15）。
- エクスプローラーで書式付きファイル（PDF）を写して使い回さないでください。写したものと元のものが同じ構文ファイルを使うので、写したものを保存すると、元の文書が開けなくなります。

## 3.11 印刷

確認表示の上の［印刷］（Ctrl+P）で、「印刷」の画面を出します。

- **プリンター：** 使うプリンターを選びます。用紙のトレイや両面印刷などは、［プロパティ］で、プリンターの設定の画面を開いて決めてください。
- **印刷するページ：** すべて、確認表示に出ているページ、または「1-3, 5」のように指定したページを印刷します。
- **部数：** 1〜99 部。部単位でそろえて印刷します。

用紙は A4 で、確認表示と同じページを実際の大きさで印刷します。保存していない文書も印刷できます。

> **提出用の PDF は［保存］で作ってください。** ［印刷］で「Microsoft Print to PDF」を選ぶと、ページを画像にした PDF になり、字を選んだり検索したりできません。

## 3.12 スキャンした PDF を開くとき

VA DocuMakeは、PDF の中の「字の情報」を取り出して開きます。スキャナーで読み取っただけの PDF は、紙の画像しか入っていないので、そのままでは開けません。開こうとすると、次のように知らせます（開いている文書は、そのまま残ります）。

> この PDF には、取り出せる字がありません（スキャンした画像だけで、OCR の字が入っていません）。

**Chrome で検索できても、字の情報があるとは限りません。** Chrome は、画像だけの PDF を表示するときに、その場で文字を読み取って（OCR）、検索や選択をできるようにしています。この読み取りの結果は PDF のファイルには保存されないので、ほかのソフトからは、字のない PDF のままです。

**開けるようにするには、スキャンのソフトで OCR をしてください。** OCR をすると、PDF のファイルそのものに字の情報が入り、VA DocuMakeのほか、Acrobat や Windows の検索でも使えるようになります。

- ScanSnap の場合は、ScanSnap Home のスキャンの設定で、「検索可能な PDF にする」（文字を認識して PDF に埋め込む設定）を有効にしてから、スキャンし直してください。設定の名前や場所は、ScanSnap Home の版によって違うことがあります。
- ほかのスキャナーや複合機でも、「OCR」「検索可能な PDF」「テキスト認識」などの設定があれば、有効にしてください。
- 既にある画像だけの PDF は、OCR のできるソフト（Acrobat の「スキャンと OCR」など）で、後から OCR をかけられます。

**急ぐときは、Chrome から写す方法もあります。** Chrome で PDF を開き、すべての字を選んで写し（Ctrl+A、Ctrl+C）、VA DocuMakeのエディターに貼り付けます（Ctrl+V）。読み取りは Chrome の中で行われ、外へは送られません。ただし、段落の途中に改行が入ったり、表が崩れたりするので、確認表示を見ながら直してください（仮名化してから AI に整えてもらうこともできます。第4章の注意を守ってください）。

**スキャンした画像を、AI のチャット画面に直接渡して読ませないでください。** 画像に写っている依頼者などの名前が、そのまま AI に渡ります。

## 3.13 オプション

「ファイル」の［オプション］で、次のことを変えられます。設定は、このパソコンにだけ覚えます。

- **構文ファイル（.vadm）の保存場所：** 事務所のほかの人と文書を共有するときは、共有フォルダを選んでください。
  - このフォルダには、構文ファイルだけを置いてください。書式付きファイル（PDF）や事件の資料（実名入り）は、別のフォルダに置きます。AI にフォルダごと読ませたときに、実名のファイルに届かないようにするためです。
  - ほかの人が構文ファイルを開いて実名に戻すには、同じ文書の書式付きファイル（PDF）も必要です。PDF も共有しておいてください（PDF を見つけられないときは、PDF を選ぶよう尋ねます）。
  - 保存場所を変えても、今開いている文書は、これまでの場所の構文ファイルを使い続けます。新しい文書から、新しい場所に保存します。
- **エディターの書体・字の大きさ・行の間隔：** 見やすいように選んでください。PDF の書式には関係しません。
- **AI への指示：** 構文ファイルの上に付ける、AI への指示を確かめ・直せます（［確認・修正］）。今の文書と、これから作る文書に使います。［既定に戻す］で元の指示に戻せます。記号や区切りの行を残すよう求める部分は、消さないでください。

## 3.15 よくある質問

**テンプレート（決まった文言）を使いたいときは、どうすればよいですか。**

表題・当事者の表示・署名欄など、毎回同じにしたい文言は、テキスト（.txt）かマークダウン（.md）のファイルに書いておき、［開く］で開いてください。テキストやマークダウンのファイルを開くと、保存先の決まっていない新しい文書になり、元のファイルは書き換わりません（初めて保存するときに、書式付きファイルの保存先を尋ねます）。配置などの記号（`:=: ` `--: ` など）も、そのまま書いておけます。

- テンプレートには、実際の事件の名前・番号などを残さないでください。
- 構文ファイル（.vadm）や書式付きファイル（PDF）を、テンプレートにしないでください。開いて［保存］すると、そのファイルが上書きされます。
- テキストを［開く］と、今の文書の仮名化した語の一覧は消えます。テンプレートを開いてから、仮名化してください。書いている途中の文書に入れるときは、テンプレートのファイルをメモ帳などで開いて写し、エディターに貼り付けます。
- 決まった文言を AI に書かせると、言い換えられることがあります。毎回同じにしたい文言は、テンプレートから入れてください。

**なぜ、［コピーとして開く］や［名前を付けて保存］がないのですか。**

過去の文書を写して別の文書を作ると、前の文書の情報が残っていても、VA DocuMake では見つけられないためです（Ver.110 から Ver.142 まではありましたが、取りやめました）。

- 仮名化した語は、記号に置き換わるので見分けられます。しかし、仮名化していない事件番号・日付・金額・住所や、仮名化しなかった人の名前などは、文章にそのまま残ります。別の依頼者の情報が書面に混ざると、守秘義務の問題になります。
- VA DocuMake では、文章を AI と起案するので、過去の書面を写して作る必要はあまりありません。決まった文言は、テンプレートから入れてください。
- 同じ理由で、過去の文書を［開く］で開いて書き換えるのも避けてください。保存すると、過去の文書が上書きされます。

**保存した書式付きファイル（PDF）の名前を変えたいときは、どうすればよいですか。**

エクスプローラーで、PDF の名前を変えてください。VA DocuMake は、PDF と構文ファイルを、ファイルの名前ではなく、PDF の中に書いた文書ID で結んでいます。名前を変えても、PDF からも構文ファイルからも、これまでどおり開けます。

- 名前を変える前に、VA DocuMake でその文書を［閉じる］で閉じてください。開いたまま名前を変えると、次に［保存］したとき、前の名前の PDF がもう1つ作られます（同じ文書の PDF が2つになります）。
- 別のフォルダに移したときは、PDF を［開く］で開いてください。構文ファイルから開いて PDF が見つからないときは、PDF を選ぶよう尋ねます。
- PDF を写して（コピーして）から名前を変えるのは、避けてください（3.10）。

**文書ごとに、仮名（記号）が違ってしまうことはありませんか。問題はありませんか。**

記号の字は、仮名化するたびに利用者が決めます（3.8）。同じ事件の書面で同じ人に同じ記号を選べば、文書をまたいでも記号はそろいます。VA DocuMake は、どの人にどの記号を付けたかをファイルに残さない（実名と記号の対応を、どこにも書かない）ので、そろえるのは利用者の決まりで行います。

- 1つの文書を1つの会話で扱えば、記号がそろっていなくても問題はありません。AI が見るのは、渡された構文ファイルの記号だけで、記号の意味は1通りです。
- 同じ会話や同じプロジェクトで、同じ事件の別の書面も扱うときは、記号をそろえてください。そろえていないと、前の書面の〔人名Ｃ〕が、今の書面では別の人を指すことがあります。
- 構文ファイルの AI への指示では、記号は文書ごとであり、ほかの文書の記号を書き写さないよう伝えています（そろえていない人もいるため）。記号をそろえているときは、チャットで「この事件の文書は、記号をそろえてある」と伝えてください（実名を含まないので、書いてかまいません）。
- AI の回答を取り込んだら、書式付きファイル（PDF）で、人の名前が正しい所に入っているかを確かめてください。

**仮名化をまとめて解除したいときは、どうすればよいですか。**

まとめて解除するボタンはありません。解除した語は、次に保存すると、構文ファイル（AI に渡すもの）に実名のまま書かれるためです。1語ずつ、一覧で選んで［解除］を押してください。仮名化した語の一覧を消して、別の文書を始めるときは、［閉じる］を押します。

# 第4章 AI を使うときの注意

VA DocuMakeは、AI に渡す文章（構文ファイル）の中の、仮名化した語（依頼者などの名前）を記号（〔人名Ａ〕など）に置き換えます。ただし、文章の中身（事案の経過、日付、金額など）は、そのまま AI に渡ります。AI のサービスの側で、渡した文章がどう扱われるかを、利用者が設定で決めておく必要があります。

## 4.1 AI の学習に使わせない設定（Claude）

Claude の個人向けのプラン（Free・Pro・Max）では、会話を Claude のモデルの学習（改善）に使うかどうかを、利用者が設定で選びます。依頼者に関わる文章を扱う場合は、**学習に使わせない設定**にしてください。

**設定のしかた（パソコンの claude.ai）**

1. 画面の左下の名前を押し、設定のメニューを開きます。
2. 「設定（Settings）」を開きます。
3. 「プライバシー（Privacy）」を開きます。
4. 「AI モデルの改善に協力する（Help improve our AI models）」のスイッチを**切り**ます。

スマートフォンのアプリでも、設定 → プライバシー の同じ項目で切り替えられます。画面の項目名は、表示の言語や Claude の版によって少し違うことがあります。

**切ったときにどうなるか**

- これからの会話は、今後のモデルの学習に使われません。前に保存された会話も、今後の学習には使われません。
- すでに始まっている学習や、学習を終えたモデルからは、取り除かれません。そのため、**依頼者に関わる文章を初めて扱う前に**切ってください。
- 学習を許している場合、会話は個人と結び付かない形で最長5年保存されます。許していなければ、会話を消すと、30日以内に Anthropic の保存先から消えます。

## 4.2 設定を確かめる方法（AI に尋ねない）

設定が切れているかは、**claude.ai の設定の画面で、利用者が自分で確かめて**ください。

AI（Claude）は、会話の中から利用者のアカウントの設定を見ることができません。「学習の設定は切れていますか」と AI に尋ねても、AI は一般的な説明をしたり、推測で答えたりするだけで、実際の設定を確かめた答えにはなりません。VA DocuMakeも、外部と通信しないので、設定を確かめることはできません。

事務所で使う場合は、利用者それぞれが、自分のアカウントで設定を確かめてください（設定はアカウントごとです）。

## 4.3 設定を切っていても、学習などに使われることがあるもの

- **評価のボタン（👍・👎）**：押すと、その会話の全体が5年間保存され、学習に使われることがあります。依頼者に関わる会話では、**押さないでください**。
- **安全の確認で引っかかった会話**：利用規約に反するとして自動で判定された会話は、安全のための仕組みの改善に使われることがあり、最長2年保存されます。
- **自分から学習への提供に同意した場合**：テストへの参加などです。

## 4.4 学習に使われない使い方

- **シークレットチャット（Incognito chats）**：学習の設定がどちらでも、学習には使われません。
- **事務所向け・会社向けのプラン**（Claude for Work〔Team・Enterprise〕、API）：個人向けとは別の規約で扱われます。事務所で契約している場合は、契約の内容を確かめてください。

## 4.5 AI に渡すときの注意

- **AI のチャット画面に、実名を書かないでください。** 追加の指示は「原告」「被告」「依頼者」などと書けば足ります。チャット画面に直接書いた実名は、VA DocuMakeでは防げません。
- **構文ファイルのフォルダ（ドキュメント\VA DocuMake\構文ファイル）には、書式付きファイル（PDF）や事件の資料を置かないでください。** フォルダの中を読める AI（Claude Code など）に渡したときに、実名の入ったファイルに届いてしまいます。
- **Claude Code を使うときは、作業フォルダを「構文ファイル」フォルダだけにしてください。** ほかのフォルダを作業フォルダにしたり、作業フォルダを足したりしないでください。作業フォルダの中のファイルは、AI が断りなく読めるため、実名のファイルが紛れ込んでいると、読まれてしまいます。
  - 直す文書は、エディターの上の［パスをコピー］でコピーしたパスを貼って指定します（「このファイルを直して：<貼ったパス>」）。
  - このフォルダには、ほかの事件の構文ファイルも並んでいます。構文ファイルの先頭の AI への指示に、同じフォルダのほかの構文ファイルを開かないよう書いてあります。
  - 作業フォルダの外のファイルを読む許可を求められたら、許可しないでください。
  - Claude Code は、作業フォルダの上のフォルダ（ドキュメント など）にある CLAUDE.md も読みます。そこに事件の情報を書かないでください。
- **Claude（デスクトップ・Web）に添付するときは、**［パスをコピー］でコピーしたパスを、添付の画面の「ファイル名」の欄に貼ると、その文書の構文ファイルを選べます。
- **設定ファイル（%APPDATA%\VA DocuMake\settings.json）は、AI に渡さないでください。** PDF を保存したフォルダの名前（依頼者の名前が入っていることがあります）が書かれています。
